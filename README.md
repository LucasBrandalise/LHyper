# YT Downloader

Aplicativo desktop em Python + PySide6 para baixar vídeos e converter áudio.

## Requisitos

- Python 3.14
- PySide6
- yt-dlp
- FFmpeg

## Como executar

```bash
python run.py
```

Ou, usando a venv do projeto:

```bash
.venv\Scripts\python.exe run.py
```
